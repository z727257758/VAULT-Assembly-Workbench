# VAULT 装配工作台

**VAULT Assembly Workbench**

**Unofficial Companion Tool for the USSA Design VAULT modular storage system.**

面向 **USSA Design VAULT 模块化收纳系统的非官方辅助工具**。本项目只是为了让已获取原模型的用户更方便地查找零件、配置抽屉、预览装配和准备打印文件；不提供或替代原设计模型包。

独立的 Windows 桌面程序，使用 Rust + eframe/egui + wgpu。
没有 WebView、HTML 前端或本地 HTTP 服务。

## 运行

1. 通过原作者渠道获取 VAULT 模型包，解压到本仓库之外，保留原目录结构。
2. 双击 `启动VAULT装配工作台.cmd`。有本地构建产物时直接启动；否则通过 Cargo 编译运行，需要 Rust 工具链和 Windows C++ 构建工具。
3. 点击“打开模型库”，选择包含 `01. DRAWERS` 等文件夹的根目录。首次启动需手动选择模型库，成功打开后记录到本地 `state/settings.toml`，下次启动自动恢复。打开目录对话框也会定位到上次目录；目录失效时提示重新选择，并优先定位到仍存在的上级目录。取消选择或打开失败不会覆盖上次成功记录。仓库默认配置不包含模型库路径。
4. 配置抽屉、内部收纳和打印清单，检查预览后导出。

普通 STL 的查找、预览和导出不需要 OpenSCAD。生成 Gridfinity 盒子需要 OpenSCAD，将便携版放入下述相对目录即可自动找到。

## 功能与操作

### 装配配置

- 支持 S/M/L/XL 宽度、3–7 格深度、1F/2F/4F 层高查找；XL 限 1F。完整配置面向普通抽屉，Sustainer 盒子方案暂未开放。
- 可选标准或隐藏钥匙；齿条默认加入必备配件。Facade Cap 按标准面板规格自动配置数量，XL 分体方案暂保留估计。
- 内部配置可选“无内部配置”“Gridfinity 收纳”或“收纳隔板”，收纳底板与隔板互斥。
- 全部组件可按文件夹、名称及用途查找，工具箱和改装件支持单件预览。
- 保存与载入 TOML 方案，保留布局、标签和配色设置。

打印清单中的数量表示源文件份数。一个 STL 可能包含多个实体，例如 Springs；展示时拆分不会改变源文件或自动改变打印份数。

### 三维预览

左键拖动旋转，右键或中键拖动平移，滚轮缩放，双击适配画面。单击模型或右侧装配树选中零件，可查看尺寸、隔离选中或显示全部。

支持标准视角、三视图、装配与爆炸预览、外壳透明。三视图显示选中零件，未选中时显示第一个零件；尺寸假定源 STL 单位为 mm。

修改配置后自动更新预览，无需手动刷新。加载期间保留当前画面；新配置会替代过期任务。单件查看后可通过“装配预览”返回。

### 收纳隔板

在“抽屉内部配置”中选择“收纳隔板”，进入编辑器放置、选择或移除隔板。布局随方案保存，并同步到装配预览和打印清单。切换内部配置时会移除不兼容的配置。

### Gridfinity 收纳

选择底板类型后，点击“编辑 Gridfinity 盒子”。支持 S/M/L 非分体抽屉，可用网格随规格及底板类型变化。

- 点击“添加盒子 / 拖入”自动寻找空位，或将盒子拖入指定网格；也可在空白网格拖框创建盒子。
- 选中已有盒子后，拖动盒体移动，拖动左右边缘调整宽度；深度在统一配置中设置；支持复制和删除。
- 拖动时绿色表示可放置，红色表示冲突。越界、重叠或释放到画布外时保留原布局；Esc 或右键取消拖动。
- 高度可随抽屉层高自动配置，也可手动降低：1F 为 4U、2F 为 10U、4F 为 24U。1F 的 4U 盒体总高约 31.55 mm，按标称安装位置距抽屉上沿约 1.65 mm。每个盒子可设置标签台和取物圆弧，新建盒子默认开启取物圆弧，位于标签台对面的前壁；简化预览也显示这一方向的近似圆弧。
- “所有小盒统一配置”直接设置全部盒子的深度、高度、取物圆弧、标签台和可拆结构，以及字体、字号、凹凸字、刻深及文字偏移；修改立即生效，新建、复制或拖入的盒子自动沿用。取消按盒子单独配置和来源 / 目标批量应用入口。统一修改深度导致越界或重叠时整次取消。
- 网格右侧紧凑显示所选标牌正面预览。标牌使用与导出一致的实际字体轮廓、字号及同类型配色，支持两行、凹凸字和偏移；盒内输入草稿也会预览，Esc 取消后恢复。文字超出 34 × 10 mm 安全区时提示调整。字体读取和轮廓处理在后台完成。
- 网格内直接编辑标签：双击盒内，或选中后直接键入 / 按 F2。Enter 确认，Shift+Enter 换行，点击其他位置也可确认，Esc 取消。输入期间仅保留草稿，确认后更新三维与导出；非空文本自动启用标签台和文字，清空则恢复空白标牌。输入中文需要放大字号时，全体字号统一提高到最低 5 mm。
- 标签文本在“本盒标签文本（单独设置）”逐盒编辑。统一设置保留各盒文本和文字启用状态；仅位置、宽度与标签文本逐盒设置。旧方案按最小编号盒子的参数统一，深度采用原有最小深度以保持位置并避免新增重叠。
- 底板与盒子整体作为内部收纳配置；移除全部盒子可保留底板，选择“无内部配置”则移除整套内部配置。

启用“标签台 → Cullenect 可拆标牌”后，盒体生成安装槽，打印清单另外增加 `Cullenect-编号.stl` 标牌。标牌固定为 1 格宽（36 × 11 × 1.2 mm），较宽的盒子也使用居中的 1 格标牌。原有配置仍使用一体式标签台。

标牌独立支持原有文字、字体、凹凸字及颜色设置；文字安全区为 34 × 10 mm，字高 / 刻深为 0.2–0.4 mm，推荐 0.2 mm。留空仍生成空白标牌。STL 分为独立文件，3MF 分为独立对象并强制将可拆标牌放在专用打印盘，即使与盒体同色也不混盘；可分别勾选导出。仅生成标牌不需要 OpenSCAD。盒体使用单色打印，双色标牌另开打印任务，可避免因盒顶文字产生高料塔。

接口参考 [Cullenect Labels 的公开尺寸](https://github.com/CullenJWebb/Cullenect-Labels)，用现有 Rust 实体运算实现，未新增 SCAD 源码或依赖。接口与标牌尚未经过实体试打印验证，建议先打印一组检查配合。尺寸、设计差异及许可见 [Cullenect 说明](docs/CULLENECT.md)。

首次生成新尺寸盒体可能需要几十秒。程序先显示简化预览，精确模型完成后自动替换；导出始终使用精确模型。盒体和文字分别缓存，修改文字复用盒体，移动盒子复用已有模型，多个不同盒体可并行生成。

安装本项目使用的 OpenSCAD：

```powershell
powershell -ExecutionPolicy Bypass -File tools/setup-gridfinity.ps1
```

程序优先按顺序查找工作区根目录（便携部署时为程序所在目录）下的相对位置：

1. `tools/openscad/openscad.com`
2. `tools/openscad/openscad-2021.01/openscad.com`（安装脚本的默认位置）
3. `openscad/openscad.com`

请保留 OpenSCAD 便携包的完整文件，不能只复制 `openscad.com`。以上目录均不存在时，再检查 `VAULT_OPENSCAD`、系统安装目录和 `PATH`。`VAULT_OPENSCAD` 可填写绝对路径，也可填写相对于工作区根目录的路径，不依赖启动命令的当前目录。

缓存位于 `state/gridfinity-cache/`；安装完成后生成过程不需要联网。

### 标签文字与颜色

Label 编辑基于用户模型库中的 `Label.stl`，保留标签外形和安装结构。支持最多两行、48 个字符，微软雅黑中英文或 Arial，凹字/凸字/平面分色、字号、深度及位置调整。Gridfinity 盒子的标签台也支持文字编辑。超出可用区域时会提示调整。

点击三维零件，在右侧属性选择打印颜色，或选择“跟随默认”。工具栏“配色”可编辑 6 个 Bambu PETG Basic 颜色槽。同一源文件的所有份数共用颜色，属性中会提示联动范围。

Gridfinity 小盒与 Cullenect 可拆标牌分别按同类型共用颜色，选中任意一个修改会同步全部同类，新建同类也继承。“配色”窗口每种类型仅显示一行；标牌底片和文字可分设颜色。旧版逐盒颜色按已设置的最小编号统一，下一次修改会合并为类型设置。

选中 Label 或带标签台的 Gridfinity 盒子，还可单独设置“文字颜色”，或选择“跟随底板”。凸字独立着色；凹字给凹底着色并保留凹陷；平面分色让文字与底板顶面齐平，仅改变材料颜色，保持原外形、厚度与安装结构。平面模式中的“颜色层厚”控制表面以下的文字材料深度（普通标签/盒子 0.2–0.8 mm，可拆标牌 0.2–0.4 mm），不形成凹凸。需为文字选择不同且有对比的耗材颜色，并导出 3MF；STL 不保存颜色，平面模式下只有原来的平整外形。同色耗材槽不会显示可见文字。颜色改变即时显示，不重新生成几何。

“打印颜色预览”位于“外壳透明”右侧。开启后，选中件用浅蓝色包围框标识，保留实际颜色。

## 导出与打印

导出范围是打印清单中勾选的文件及其份数，不取决于视口显隐、单件预览或爆炸状态。导出按打印朝向选项摆盘：平面分色的独立标牌可字面朝下，其余零件保留源模型打印方向。不使用显示装配位置，也不修改原始 STL。

| 格式 | 内容 |
| --- | --- |
| STL 文件夹 | 每份单独文件；标签和盒子包含生成后的真实几何，不携带颜色、支撑参数或打印盘信息。 |
| 3MF 工程 | 包含 P1S / 0.4 mm 参考配置、对象耗材槽、标签多色区域及打印盘归属；由用户在 Bambu Studio 中作为工程打开并切片。 |

### 摆盘与多色

3MF 的六个颜色槽统一使用 **Bambu PETG Basic** 官方 P1S 兼容耗材预设（`GFG00`），包含温度、流量和冷却等参数；各槽颜色仍可独立设置。已导出的旧 3MF 需要重新导出才能采用新材料预设。

3MF 支持打印板类型、边距、零件间距、外侧 Brim、平面旋转 90°、自动增加盘、层高、壁数和填充率设置。

“平面分色标牌字面朝下”默认开启：仅将启用平面文字的独立 Label 和 Cullenect 可拆标牌整体翻转 180°，底板与文字共用同一变换，字面贴床至 Z=0；不镜像字形。此选项独立于平面 90° 旋转，随方案保存，关闭即可恢复字面朝上。盒子一体标签台、凸字、凹字及空白标签保留原打印朝向；装配预览与 STL 不受此 3MF 摆盘选项影响。

按完整耗材组合分盘：普通单色零件按颜色槽分盘，异色文字与底板保持同一对象、同一盘。相同 RGB 的不同耗材槽仍分别处理，保留各自耗材参数。

长宽比至少 3:1 的同类长条默认优先平行、端部对齐并紧凑排列：Runner Guide 与 Runner Slide 归为同组，其他长条仅与同名零件副本成组。先完成安全分盘，再在原盘内尝试两个长轴方向；保留材料分组、份数、零件间距及 Brim 占地，不增加盘数。关闭 90° 旋转时遵守源文件方向；整组无法安全放入时保留原布局。整理后重新检查整盘凸包、边界与零件间距。

可勾选“每盘零件整体居中”，单件居中，多件保持相对位置和间距整体居中；若触及避让区域，或整盘轮廓凸包进入左前禁放区，则保留原安全摆放。此选项默认关闭。

P1S 参考平台为 256 × 256 mm，限高 250 mm，避开左前 18 × 28 mm 禁放区。默认边距 0.5 mm、零件间距 6 mm、Brim 关闭；摆盘同时检查模型与 G-code 坐标，保留 P1S 预设的 Y=2 mm 喷嘴偏移，因此模型前缘至少留出 2 mm 加所设边距，旋转、分盘与居中均使用这一限制；自动避让起始擦料线的 L 形区域（前沿两条横线及右侧回折），额外保留 2 mm 缓冲并叠加边距与零件间距，Brim 及其与模型的间隙也参与避让；同时检查整盘占地矩形的凸包，避免零件各自安全但整体凸包穿过左前禁放区而触发 Bambu Studio 越界提示，必要时另选位置或分盘。导出以最终制造网格的实际顶点计算占地并归一化原点，摆盘完成后再次检查边界与整盘凸包；超过可用尺寸时提示错误，不缩放或切割模型。自动分盘最多 36 盘，单次最多 1000 份。

### 支撑与切片

勾选“为 Turn On Supports 零件启用支撑”，3MF 会对匹配文件名的对象启用支撑。全局支撑开关仍可能显示关闭，应查看对应对象设置；实际支撑在切片后生成。STL 不携带此设置。

“模块底部卡扣局部支撑”默认开启：识别标准 S/M/L Module 底部卡扣的悬空平面，在 3MF 中保存强制支撑涂绘，并对该对象启用手动树状支撑（仅从打印板生成）。S/M 为两处，L 为四处；不匹配已知尺寸的网格和分体型号不自动标记。可在 Bambu Studio 的支撑绘制工具中查看或修改，支撑实体在切片后生成；STL 不携带涂绘，原始模型不修改。此设置与按文件名启用支撑独立，随方案与导出设置保存。

3MF 是未切片工程，不会自动启动 Bambu Studio 或发送到打印机。打印前检查耗材映射、支撑、首层与平台范围；多色打印还需检查 AMS、冲刷量及擦拭塔设置。参考配置的擦拭塔默认关闭，摆盘不计算切片后支撑和擦拭塔的额外占位。

## 范围与限制

- 装配预览和关系约束用于辅助理解，不是完整 CAD 装配或制造验证；五金未建模，部分特殊型号仍使用估计位置。
- 工具箱、改装件和特殊系列可浏览及单件预览，尚无完整专用装配模板。
- “外壳透明”用于观察内部，不是精确的多层透明模拟。
- 当前面向 Windows，尚未验证 macOS/Linux。主要界面支持中英文，PDF 使用系统阅读器。
- 大模型可能加载较慢；单文件上限 250 MB，单场景上限 800 万独立三角面。

## 开发与调试

```powershell
cargo run
cargo fmt --check
cargo test
cargo clippy --all-targets -- -D warnings
cargo build --release
```

需要本地模型库的集成测试：

```powershell
$env:VAULT_MODEL_ROOT = '你的模型库目录'
$env:VAULT_EXPORT_TEST_ROOT = $env:VAULT_MODEL_ROOT
$env:VAULT_GRIDFINITY_TEST = '1'
cargo test
```

Gridfinity 相关测试需要配置生成器。原生界面检查使用真实窗口和 GPU，截图写入 `output/`：

```powershell
cargo run --release -- --smoke-test
```

装配坐标、关系编辑、爆炸方向重排和相交检查通过调试模式开启：

```powershell
cargo run -- --debug-ui
```

调试调整只影响展示配置。包围盒重叠或网格相交结果不能直接证明穿模、公差合理或装配可制造。装配配置见 `state/`。

## 工作区结构

| 目录 / 文件 | 用途 |
| --- | --- |
| `src/` | Rust 源码与 WGSL 着色器 |
| `config/` | 首次启动配置、展示规则和打印参考配置 |
| `vendor/gridfinity-rebuilt/` | 保留许可证的第三方 SCAD 生成源码 |
| `tools/` | 生成器安装脚本；本地安装的 OpenSCAD 不纳入 Git |
| `state/` | 用户设置、装配配置和生成缓存，不纳入 Git |
| `output/` | 本地导出、截图与验证报告，不纳入 Git |
| `target/` | Cargo 构建产物，不纳入 Git |
| `Cargo.lock` | 锁定依赖版本 |

原模型库应放在工作区之外；请勿将原始模型包或含原模型的导出工程随软件发布。
