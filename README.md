# VAULT 装配工作台

**VAULT Assembly Workbench**

**Unofficial Companion Tool for the USSA Design VAULT modular storage system.**

面向 **USSA Design VAULT 模块化收纳系统的非官方辅助工具**。本项目只是为了让已获取原模型的用户更方便地查找零件、配置抽屉、预览装配和准备打印文件；不提供或替代原设计模型包。

独立的 Windows 桌面程序，使用 Rust + eframe/egui + wgpu。
没有 WebView、HTML 前端或本地 HTTP 服务。

## 运行

1. 通过原作者渠道获取 VAULT 模型包，解压到本仓库之外，保留原目录结构。
2. 双击 `启动VAULT装配工作台.cmd`。有本地构建产物时直接启动；否则通过 Cargo 编译运行，需要 Rust 工具链和 Windows C++ 构建工具。
3. 点击“打开模型库”，选择包含 `01. DRAWERS` 等文件夹的根目录。首次启动需手动选择模型库，成功打开后记录到本地 `state/settings.toml`，下次启动自动恢复。打开目录对话框也会定位到上次目录；目录失效时提示重新选择，并优先定位到仍存在的上级目录。取消选择或打开失败不会覆盖上次成功记录。仓库默认配置不包含模型库路径。
4. 配置抽屉、内部收纳和打印清单，检查预览后导出。

STL 采用流式读取，不再按 250 MB 文件大小拒绝正常模型；单文件最多 800 万三角形、场景最多 1600 万份唯一网格三角形。大网格按整三角形分块上传显卡，不简化或缩放源几何。XL3 Module 1F（约 337 MB）已纳入读取与原生渲染回归；XL 分体抽屉的整体安装面校准限制仍单独提示。

普通 STL 的查找、预览和导出不需要 OpenSCAD。生成 Gridfinity 盒子需要 OpenSCAD，将便携版放入下述相对目录即可自动找到。

## 功能与操作

### 配置器界面

原生界面的布局与视觉参考 [ReVault 配置器](https://revault.reventonc.com/)，继续使用本项目的 Rust、egui 与 wgpu 实现：

- 左侧约 400 像素侧栏统一使用“1 · 整体配置 / 编辑内容 → 2 · 打印清单”导航。项目切换、新建、预设和名称编辑统一放在全局顶部栏；模型库、资料与设置位于右侧。零件库与装配说明放在“资料”菜单。
- 整体页按尺寸、顶部配置、层卡片、底座搭建；顶部与底座可折叠，左右成员明确标注，内部配置与标牌入口按抽屉分开。层卡片的边框、标题和留白均可点击展开；标题再次点击收起，内容区留白保持展开。展开后标题右侧直接显示复制与删除，底部提供上下移动和导出勾选，左侧手柄保留拖动排序。按钮、复选框和下拉框独立响应点击。空顶盖和底部使用同样可整卡展开的虚线卡片。
- 点击抽屉的配置摘要，在同页浮动面板编辑类型、内部收纳和标签；侧栏展开对应层，唯一三维视口保留完整组合并对目标特写。切换目标继续在同一场景编辑，关闭面板恢复原整体视角。盒子、底板和标签的“特写”也使用这个视口。
- 浮动面板的“运动预览”提供箱盖开启／合盖、抽屉拉出／推回、暂停／继续和速度控制。运动沿关节轨迹进行：先释放锁扣再抬盖，落盖后扣锁；支承箱保持闭盖，抽拉限制在有效行程内，各子抽屉独立联动内部件。动画不重建网格，目标姿态随项目保存；轨迹仍为展示，未验证实物连续行程。
- 整体与单件的打印清单都在侧栏内切换，配置与清单分别保留滚动位置。整体清单与层卡片同为自上而下顺序，并列出随配置导出的顶盖、底座和外部配件；子抽屉清单只列自身零件，共用外壳在整体清单中核对。固定底栏显示统计、打印板预览与导出入口，明确区分整个项目与当前模块；模块导出包含其共用外壳和所有子抽屉。
- 三维视口使用灰色渐变背景。“零件”按钮按需展开或收起装配树与属性栏，编辑页不再固定占用右侧和底部空间；打印板模式保留打印盘属性。“视图”菜单提供标准视角、外壳透明、打印颜色和三视图。
- “整体配色 / 当前抽屉配色”打开对应编辑器；“设置”提供语言与浅色／深色切换，并保存在 `state/settings.toml`。旧设置文件默认使用浅色。

### 装配配置

装配、运动和爆炸展示入口统一由 `constraints::AssemblyRules` 管理；参数、手册依据及估算边界见 [装配与运动规则](docs/ASSEMBLY_RULES.md)。

- 支持 S/M/L/XL 宽度、3–7 格深度、1F/2F/4F 层高查找；XL 限 1F。可选择普通抽屉或 Sustainer 箱子方案。
- 标准抽屉 RUNNER 按高度配置：1F 为 1 对、2F 为 2 对、4F 为 4 对；导轨、滑轨、止挡同步增加，逐层使用源网格槽位定位。旧方案加载时更新数量，新增装配位置保持未校准。
- 可选标准或隐藏钥匙；齿条默认加入必备配件。Facade Cap 按标准面板规格自动配置数量，XL 分体方案暂保留估计。
- 内部配置选择“平底 / 分隔板”；平底可开启 Gridfinity 底板并编辑盒子，收纳底板与隔板互斥。
- 全部组件可按文件夹、名称及用途查找，箱子配件和改装件也支持单件预览。
- 保存与载入 TOML 方案，保留布局、标签和配色设置。

打印清单中的数量表示源文件份数。一个 STL 可能包含多个实体，例如 Springs；展示时拆分不会改变源文件或自动改变打印份数。

### 多规格盒子 / 抽屉组合

默认从层式项目进入，按“项目 → 整体宽深 → 层与内部配置 → 打印清单 → 导出”操作：

- **项目菜单**：切换本地项目、新建、打开 TOML 文件或保存为文件。项目名称可直接编辑；有效项目及当前项目自动保存在 `state/projects.toml`，退出时补存最后修改。项目文件在后台读取，不改写模型库文件。
- **预设组合**：项目栏的“预设”可新建 10 组组合：S3 紧凑四抽、M4 日常抽屉塔、M5 高低抽组合、L4 整块与双列、L3 双列配翻盖箱、M3 抽屉与翻盖箱、XL5 S＋M 三层塔、XL4 S＋M 混合塔、S6 深款分盖组合、M7 深款工作塔。预设包含共用壳体、多层混搭及分体顶盖，使用整体配色并从空白标牌和内部配置开始。新项目保留原项目；缺少源文件或规格不兼容时拒绝创建整个预设。预设的装配位置仍为估算。
- **整体尺寸**：统一选择 S/M/L/XL 宽度和 3–7 格深度。更改规格保留能继续使用的标牌、配色及内部配置；不兼容时拒绝修改，可明确选择重置内部配置。XL 默认使用 S＋M，整块 XL 抽屉仍受原有安装面校准限制。
- **顶部配置**：宽深跟随整体尺寸，顶部组合方式独立于抽屉层。分体顶层可选一块整体 L / XL 顶盖，或 S＋S / S＋M 的分体顶盖；分体时分别选择类型与提手。改整体宽深或拆合顶层时自动匹配新规格，并同步到预览、打印清单和导出。整块转分体时沿用整块类型；分体合为整块时采用从左到右首个已选顶盖。旧方案的分体类型保留；含翻盖箱的顶层保留箱子自带顶盖，不能加跨箱的整体抽屉顶盖。定位仍为网格估算，未经实物确认。
- **层卡片**：自上而下展示，可选择 1F/2F/4F 高度；L 支持整块或 S＋S，XL 使用 S＋M。支持添加抽屉层／箱子层；点击整张层卡片展开，复制、删除、导出勾选与移动直接显示，保留拖动排序和撤销／重做。顶盖和底座在塔的两端配置，背板、把手等按成员配置。
- **层内抽屉**：2F 模块可放一个 2F 或两个 1F 抽屉；4F 可放一个 4F、两个 2F、四个 1F，或 2F＋1F＋1F 的三种顺序。卡片顺序与三维预览一致；一个模块只保留一份整高壳体，不重复使用多个小壳体冒充整层。
- **内部与标牌**：点击对应抽屉的配置摘要，在浮动面板中编辑内部和标签，按需打开 Gridfinity、隔板及完整标牌编辑器。主预览始终保留整个组合，通过镜头对目标特写；共用外壳中的子抽屉分别保留文本、内部布局和配色，修改实时同步。
- **打印清单**：侧栏切换到按层／抽屉组织的清单，独立勾选零件和调整份数；固定底栏显示总高、STL 种类与源文件份数。用料等待切片结果，不按包围盒推算重量。共享模块和各子抽屉分别生成打印工程，保留各自真实标牌文字，不重复导出壳体。

整体页默认显示层配置与大预览；需要时可打开零件属性面板。四种预览和标牌入口继续保留。旧的独立并列组合完整保留，可查看、编辑和保存，不自动改成不同装配。

选中对象显示毫米尺寸线，左侧列出对象和组合的“宽 × 深 × 高”。尺寸从后台的实际源 STL 顶点计算闭合外形（含标签、卡扣等外伸件），不是把旋转前包围盒当作实物尺寸；源文件单位假定为 mm。开盖预览不改变闭合尺寸读数。

堆叠规格遵循原版 01_Instructions Manual.pdf 第 8 页：同宽同深可混合盒子与抽屉；支持 **L ↔ S＋S、XL ↔ S＋M**。成组支承必须同深且顶面齐平，不允许悬空、空间重叠或自由偏移。侧向插入会为新对象腾出位置并保持原有堆叠关系；不兼容时显示原因。旧方案继续兼容，原放置索引仅作为内部保存信息，不再显示为编辑概念。

每个成员分别保存内部布局、标签、打印勾选、份数、配色和开盖角度。保存方案包含整个组合，旧的单装配 TOML 仍可载入。整体页默认导出整个装配，单件页默认只导出当前成员；导出窗口也可选择“勾选成员”。导出前按成员列出零件和份数（包含外部配件），并提示未勾选项目。批量导出按成员分别生成 STL 文件夹或 3MF，附带组合方案及 exported-members.json 成员索引；当前不合并成一个跨成员 3MF。

组合预览用箱体和闭合顶盖的网格安装面估算定位，背面对齐，不再按全部零件的外包围盒累加高度。作为上层支承的盒子在整体预览中闭盖，保存的单件开盖角度不变。规格兼容、网格安装面与成员内部检查均不代表连接器啮合、承载或实物装配已验证。缺少安装面朝向校准的 XL 分体抽屉会明确报错；XL 盒子可参与组合。详细规则与验证边界见 [组合规则](docs/COMBINATION_RULES.md)。

### 三维预览

左键拖动旋转，右键或中键拖动平移，滚轮缩放。整体装配页双击模型进入对应成员编辑页，双击空白或点击“适配画面”重置视图；单件页双击适配画面。单击模型或右侧装配树选中零件，可查看尺寸、隔离选中或显示全部。

预览工具栏提供“整体 / 爆炸 / 分层 / 打印板平铺”四种模式，并保留“编辑标牌”入口。支持标准视角、尺寸三视图和外壳透明；三视图显示选中零件，未选中时显示第一个零件，尺寸假定源 STL 单位为 mm。

- **整体**保留组合的装配位置；**爆炸**先按层和并排关系拉开各成员，再沿各自的拆装方向展开零件。完整展开时按各成员的展示范围留出间隔，可用“展开程度”调节 5%–100%，点击“整体”恢复闭合。该展示间隔不代表机械配合或无干涉验证。
- **分层**沿高度以固定层间距展开。组合按成员底部高度分层，同层的并排成员保持在一起；单成员按外壳、导轨、抽屉与前面板、底板、内部收纳及顶盖分组。分层只改变当前展示，不写入装配坐标。
- **打印板平铺**在后台读取制造网格，与 3MF 共用最终网格、份数、分色、标牌朝向及摆盘规则；按 256 × 256 mm 打印板展示盘号、成员、份数和耗材槽。可切换全部 / 勾选 / 当前成员，查看全部打印板或单盘，并切换俯视与立体。成员分别分盘，与现有逐成员导出一致；不是跨成员合盘，也不包含切片后支撑、擦拭塔或打印路径。
- 平铺只展示打印清单勾选项，不受装配预览显隐影响。修改文字、颜色、份数或打印设置后自动重新计算；点击零件可定位所属盘，选中标牌可直接返回编辑，Gridfinity 与 Cullenect 保留原有编辑器。


修改配置后自动更新预览，无需手动刷新。加载期间保留当前画面；新配置会替代过期任务。单件查看后可通过“装配预览”返回。

### Sustainer 箱子装配

在“装配配置 → 方案类型”选择“盒子（Sustainer）”，按宽度、深度、层高自动生成独立打印清单和装配预览。S/M 使用其原有箱体；L/XL 可选择平底、隔板槽或密封分区箱体。深度 6–7 可切换整盖与分体顶盖，分盖自动包含两个盖片和连接件。

“开盖”控制顶盖的铰链关节，上铰链和分体盖片随顶盖运动；下铰链、轴杆、底部堆叠卡闩及前锁面板保持在箱体上。展示范围为 0–110°，不是经过验证的机械行程。支持爆炸、透明、选中、隔离和配色；多实体铰链、轴杆及销钉拆分为显示实例，打印份数仍按源 STL 计算。箱子的打印勾选和份数独立于完整装配预览。

盒子底部共用 `01. DRAWERS/07. Universal/Latch.stl` 堆叠卡闩：S/M 各 1 个，L/XL 各 2 个。按实际安装槽定位，归入箱体组件，爆炸时向下展开。

箱子和抽屉切换时保留各自的选型与打印清单。TOML 方案保存箱体类型、顶盖方式和开盖角度；校准文件使用 `state/assembly-sustainer-*.toml`，与同尺寸抽屉分开。

箱子使用真实 STL 的双截面孔轴、圆柱弧及安装面定位，界面显示配合检查和偏差。锁扣关系为“支座 → 内件 → 外件”，分别绕大小销轴转动；支座按 UP 标记贴合前面板内壁，上铰链按销轴上方的承压面定位，内扣端部双耳连接支座，中间连续轴套连接外扣。卡扣采用保留局部间隙的展示姿态，开盖前先分别转动内外扣关节至松扣状态。分盖连接件按 S/M/L/XL 分别配置 2/3/4/5 个，并核对两侧槽的轮廓和间隙。

**自动几何定位仍待实物确认。** M 规格铰链相邻端面约有 −0.125 mm 轴向间隙；XL4 后安装孔距与下铰链相差 1.4 mm，居中后每孔约偏 0.7 mm，界面保留提示。装配销钉使用伸直展示近似，打印保留原始自由形态，未做弹性受力验证；高面板标签横向止挡待核对。部分 1F 支座背面的 UP 凸字与顶盖内沿仍有局部相交提示；原有打印支撑保留，表面诊断仍有未排除的相交；孔轴检查不等于无干涉或制造验证，螺钉未建模。箱子隔板已支持壁槽布局编辑；箱子标签支持独立文字编辑及 STL/3MF 导出；箱子底板暂未接入内部编辑器。依据与限制见 [Sustainer 说明](docs/SUSTAINERS.md)。

### 箱子收纳隔板

在“盒子（Sustainer）→ 箱子内部配置”点击“配置收纳隔板…”。S/M 可直接使用；L/XL 需选择“隔板槽”或“密封分区”箱体。

- 支持添加、点击放置、拖动吸附、删除、清空、撤销重做及填满当前方向/区域。
- 槽位由当前箱体的真实网格测量；L/XL 隔板槽箱体支持纵横交叉，密封箱按固定区域匹配隔板。
- 型号和高度随箱体匹配，布局同步到三维预览、打印清单和 TOML 方案。切换尺寸或箱体类型时分别保留布局；整盖/分盖共用内部布局。
- 原装配说明书第 6 页要求先移除槽内手动支撑。程序保留原始支撑，因此表面检查会提示相关相交；几何定位尚未实物确认。

### 抽屉收纳隔板

在“抽屉内部配置”中选择“收纳隔板”，进入编辑器放置、选择或移除隔板。布局随方案保存，并同步到装配预览和打印清单。切换内部配置时会移除不兼容的配置。

### Gridfinity 收纳

选择底板类型后，点击“编辑 Gridfinity 盒子”。支持 S/M/L 非分体抽屉，可用网格随规格及底板类型变化。

- 点击“添加盒子 / 拖入”自动寻找空位，或将盒子拖入指定网格；也可在空白网格拖框创建盒子。
- 选中已有盒子后，拖动盒体移动，拖动左右边缘调整宽度；深度在统一配置中设置；支持复制和删除。
- 拖动时绿色表示可放置，红色表示冲突。越界、重叠或释放到画布外时保留原布局；Esc 或右键取消拖动。
- 高度可随抽屉层高自动配置，也可手动降低：1F 为 4U、2F 为 10U、4F 为 24U。1F 的 4U 盒体总高约 31.55 mm，按标称安装位置距抽屉上沿约 1.65 mm。每个盒子可设置标签台和取物圆弧，新建盒子默认开启取物圆弧，位于标签台对面的前壁；简化预览也显示这一方向的近似圆弧。
- “所有小盒统一配置”直接设置全部盒子的深度、高度、取物圆弧、标签台和可拆结构，以及字体、字号、凹凸字、刻深及文字偏移；修改立即生效，新建、复制或拖入的盒子自动沿用。取消按盒子单独配置和来源 / 目标批量应用入口。统一修改深度导致越界或重叠时整次取消。
- 网格右侧紧凑显示所选标牌正面预览。标牌使用与导出一致的实际字体轮廓、字号及同类型配色，支持两行、凹凸字和偏移；盒内输入草稿也会预览，Esc 取消后恢复。两行文字需要时会收紧行距，保持字号和字形比例，并保留至少 0.3 mm 的轮廓间隔；仍超出 34 × 10 mm 安全区时提示调整。字体读取和轮廓处理在后台完成。
- 网格内直接编辑标签：双击盒内，或选中后直接键入 / 按 F2。Enter 确认，Shift+Enter 换行，点击其他位置也可确认，Esc 取消。输入期间仅保留草稿，确认后更新三维与导出；非空文本自动启用标签台和文字，清空则恢复空白标牌。输入中文需要放大字号时，全体字号统一提高到最低 5 mm。
- 标签文本在“本盒标签文本（单独设置）”逐盒编辑。统一设置保留各盒文本和文字启用状态；仅位置、宽度与标签文本逐盒设置。旧方案按最小编号盒子的参数统一，深度采用原有最小深度以保持位置并避免新增重叠。
- 底板与盒子整体作为内部收纳配置；移除全部盒子可保留底板，选择“无内部配置”则移除整套内部配置。

启用“标签台 → Cullenect 可拆标牌”后，盒体生成安装槽，打印清单另外增加 `Cullenect-编号.stl` 标牌。标牌固定为 1 格宽（36 × 11 × 1.2 mm），较宽的盒子也使用居中的 1 格标牌。原有配置仍使用一体式标签台。

标牌独立支持原有文字、字体、凹凸字及颜色设置；文字安全区为 34 × 10 mm，字高 / 刻深为 0.2–0.4 mm，推荐 0.2 mm。留空仍生成空白标牌。STL 分为独立文件，3MF 分为独立对象并强制将可拆标牌放在专用打印盘，即使与盒体同色也不混盘；可分别勾选导出。仅生成标牌不需要 OpenSCAD。盒体使用单色打印，双色标牌另开打印任务，可避免因盒顶文字产生高料塔。

接口参考 [Cullenect Labels 的公开尺寸](https://github.com/CullenJWebb/Cullenect-Labels)，用现有 Rust 实体运算实现，未新增 SCAD 源码或依赖。接口与标牌尚未经过实体试打印验证，建议先打印一组检查配合。尺寸、设计差异及许可见 [Cullenect 说明](docs/CULLENECT.md)。

首次生成新尺寸盒体可能需要几十秒。程序先显示简化预览，精确模型完成后自动替换；导出始终使用精确模型。盒体和文字分别缓存，修改文字复用盒体，移动盒子复用已有模型，多个不同盒体可并行生成。

安装本项目使用的 OpenSCAD：

```powershell
powershell -ExecutionPolicy Bypass -File tools/setup-gridfinity.ps1
```

程序优先按顺序查找工作区根目录（便携部署时为程序所在目录）下的相对位置：

1. `tools/openscad/openscad.com`
2. `tools/openscad/openscad-2021.01/openscad.com`（安装脚本的默认位置）
3. `openscad/openscad.com`

请保留 OpenSCAD 便携包的完整文件，不能只复制 `openscad.com`。以上目录均不存在时，再检查 `VAULT_OPENSCAD`、系统安装目录和 `PATH`。`VAULT_OPENSCAD` 可填写绝对路径，也可填写相对于工作区根目录的路径，不依赖启动命令的当前目录。

缓存位于 `state/gridfinity-cache/`；安装完成后生成过程不需要联网。

### 整体配色与同步

整体页的“整体配色”可编辑六个颜色槽、按用途批量配色，并逐零件设置底色和标签文字颜色。导轨、卡扣、铰链、顶盖等零件可分别设置；同类零件跨尺寸同步，分体件及不同结构变体分别配置。细分设置优先于用途配色，可一键恢复用途配色。

窗口左侧提供最小规格 S3 / 1F 的独立三维示例，可切换抽屉与盒子、旋转、平移、缩放、展开和外壳透明；点击“爆炸”展开模型后，可直接选择内部零件；选中零件显示蓝色三维线框，在右侧固定的“所选零件”属性中点击颜色槽设置底色或文字色，也可使用“仅选中 / 显示全部”检查小零件。颜色修改实时预览，示例不更改当前组合，取消窗口不应用草稿。列表包含示例和当前组合中的零件，部分专用配件不在最小示例中。修改后点击“应用整体配色”，只更新跟随整体的成员，不改变标签文本、内部布局、打印勾选、份数或摆盘参数。

- 新建成员默认跟随整体，复制成员保留来源的跟随 / 自定义状态。
- 单独修改成员颜色后转为“自定义”，整体配色不再覆盖它；成员属性可恢复跟随。
- 左侧勾选多个成员，可批量恢复跟随，或将当前成员配色一次性复制到勾选成员。一次性复制后为自定义；用途配色跨规格生效，单独源文件的覆盖仅匹配相同源文件。
- 整体配色与成员跟随状态保存到方案。旧方案保留原有独立配色，可手动批量设为跟随。

### 标签文字与颜色

Label 编辑基于用户模型库中的 `Label.stl`，保留标签外形和安装结构。支持最多两行、48 个字符，微软雅黑中英文或 Arial，凹字/凸字/平面分色、字号、深度及位置调整。Gridfinity 盒子的标签台也支持文字编辑。超出可用区域时会提示调整。

点击三维零件，在右侧属性选择打印颜色，或选择“跟随默认”。工具栏“配色”可编辑 6 个 Bambu PETG Basic 颜色槽。同一源文件的所有份数共用颜色，属性中会提示联动范围。

Gridfinity 小盒与 Cullenect 可拆标牌分别按同类型共用颜色，选中任意一个修改会同步全部同类，新建同类也继承。“配色”窗口每种类型仅显示一行；标牌底片和文字可分设颜色。旧版逐盒颜色按已设置的最小编号统一，下一次修改会合并为类型设置。

选中 Label 或带标签台的 Gridfinity 盒子，还可单独设置“文字颜色”，或选择“跟随底板”。凸字独立着色；凹字给凹底着色并保留凹陷；平面分色让文字与底板顶面齐平，仅改变材料颜色，保持原外形、厚度与安装结构。平面模式中的“颜色层厚”控制表面以下的文字材料深度（普通标签/盒子 0.2–0.8 mm，可拆标牌 0.2–0.4 mm），不形成凹凸。需为文字选择不同且有对比的耗材颜色，并导出 3MF；STL 不保存颜色，平面模式下只有原来的平整外形。同色耗材槽不会显示可见文字。颜色改变即时显示，不重新生成几何。

“打印颜色预览”位于“外壳透明”右侧。开启后，选中件用浅蓝色包围框标识，保留实际颜色。

## 导出与打印

导出范围是打印清单中勾选的文件及其份数，不取决于视口显隐、单件预览或爆炸状态。导出按打印朝向选项摆盘：平面分色的独立标牌可字面朝下，其余零件保留源模型打印方向。不使用显示装配位置，也不修改原始 STL。

| 格式 | 内容 |
| --- | --- |
| STL 文件夹 | 每份单独文件；标签和盒子包含生成后的真实几何，不携带颜色、支撑参数或打印盘信息。 |
| 3MF 工程 | 包含 P1S / 0.4 mm 参考配置、对象耗材槽、标签多色区域及打印盘归属；由用户在 Bambu Studio 中作为工程打开并切片。 |

### 摆盘与多色

3MF 的六个颜色槽统一使用 **Bambu PETG Basic** 官方 P1S 兼容耗材预设（`GFG00`），包含温度、流量和冷却等参数；各槽颜色仍可独立设置。已导出的旧 3MF 需要重新导出才能采用新材料预设。

3MF 支持打印板类型、边距、零件间距、外侧 Brim、平面旋转 90°、自动增加盘、层高、壁数和填充率设置。

“平面分色标牌字面朝下”默认开启：仅将启用平面文字的独立 Label 和 Cullenect 可拆标牌整体翻转 180°，底板与文字共用同一变换，字面贴床至 Z=0；不镜像字形。此选项独立于平面 90° 旋转，随方案保存，关闭即可恢复字面朝上。盒子一体标签台、凸字、凹字及空白标签保留原打印朝向；装配预览与 STL 不受此 3MF 摆盘选项影响。

按完整耗材组合分盘：普通单色零件按颜色槽分盘，异色文字与底板保持同一对象、同一盘。相同 RGB 的不同耗材槽仍分别处理，保留各自耗材参数。

长宽比至少 3:1 的同类长条默认优先平行、端部对齐并紧凑排列：Runner Guide 与 Runner Slide 归为同组，其他长条仅与同名零件副本成组。先完成安全分盘，再在原盘内尝试两个长轴方向；保留材料分组、份数、零件间距及 Brim 占地，不增加盘数。关闭 90° 旋转时遵守源文件方向；整组无法安全放入时保留原布局。整理后重新检查整盘凸包、边界与零件间距。

可勾选“每盘零件整体居中”，单件居中，多件保持相对位置和间距整体居中；若触及避让区域，或整盘轮廓凸包进入左前禁放区，则保留原安全摆放。此选项默认关闭。

P1S 参考平台为 256 × 256 mm，限高 250 mm，避开左前 18 × 28 mm 禁放区。默认边距 0.5 mm、零件间距 6 mm、Brim 关闭；摆盘同时检查模型与 G-code 坐标，保留 P1S 预设的 Y=2 mm 喷嘴偏移，因此模型前缘至少留出 2 mm 加所设边距，旋转、分盘与居中均使用这一限制；自动避让起始擦料线的 L 形区域（前沿两条横线及右侧回折），额外保留 2 mm 缓冲并叠加边距与零件间距，Brim 及其与模型的间隙也参与避让；同时检查整盘占地矩形的凸包，避免零件各自安全但整体凸包穿过左前禁放区而触发 Bambu Studio 越界提示，必要时另选位置或分盘。导出以最终制造网格的实际顶点计算占地并归一化原点，摆盘完成后再次检查边界与整盘凸包；超过可用尺寸时提示错误，不缩放或切割模型。自动分盘最多 36 盘，单次最多 1000 份。

### 支撑与切片

勾选“为 Turn On Supports 零件启用支撑”，3MF 会对匹配文件名的对象启用支撑。全局支撑开关仍可能显示关闭，应查看对应对象设置；实际支撑在切片后生成。STL 不携带此设置。

“模块底部卡扣局部支撑”默认开启：识别标准 S/M/L Module 底部卡扣的悬空平面，在 3MF 中保存强制支撑涂绘，并对该对象启用手动树状支撑（仅从打印板生成）。S/M 为两处，L 为四处；不匹配已知尺寸的网格和分体型号不自动标记。可在 Bambu Studio 的支撑绘制工具中查看或修改，支撑实体在切片后生成；STL 不携带涂绘，原始模型不修改。此设置与按文件名启用支撑独立，随方案与导出设置保存。

3MF 是未切片工程，不会自动启动 Bambu Studio 或发送到打印机。打印前检查耗材映射、支撑、首层与平台范围；多色打印还需检查 AMS、冲刷量及擦拭塔设置。参考配置的擦拭塔默认关闭，摆盘不计算切片后支撑和擦拭塔的额外占位。

## 范围与限制

- 装配预览和关系约束用于辅助理解，不是完整 CAD 装配或制造验证；五金未建模，部分特殊型号仍使用估计位置。
- Sustainer 提供按孔轴和安装面定位的装配预览，保留源件不一致提示；改装件和其他特殊系列仍以浏览及单件预览为主。
- “外壳透明”用于观察内部，不是精确的多层透明模拟。
- 当前面向 Windows，尚未验证 macOS/Linux。主要界面支持中英文，PDF 使用系统阅读器。
- 大模型可能加载较慢；单文件上限 250 MB / 800 万三角面；一次加载的不同源文件合计最多 1600 万三角面，组合显示几何也单独限制为 1600 万独立三角面。组合成员共享加载缓存，达到预算时在读取下一份网格前停止。


使用已选择的只读模型库（或 `VAULT_MODEL_ROOT`）核查全部预设的表面相交：

```powershell
cargo run --release --locked -- --audit-presets
# 只核查一个预设；本次报告只包含该预设
cargo run --release --locked -- --audit-presets --preset-id wide-l4
```

报告写入 `output/preset-audit/report.md` 与 `report.json`，并保存各预设的 TOML 配置。成员内部按相同配置复用闭合状态诊断；成员之间分别检查闭合、45% 和完整展开三个采样状态，容差 0.01 mm。详细结果包含零件路径、实例编号和成员间相交坐标；未完成的检查单独报错。诊断保留原始模型中的表面相交结果，需结合原手册与实际安装面核对。检查不覆盖完全包容、共面接触、连续运动或制造公差，未检出相交不能作为 CAD 装配或制造验证。

装配坐标、关系编辑、爆炸方向重排和相交检查通过调试模式开启：

```powershell
cargo run -- --debug-ui
```

装配确认与保存时的几何指纹绑定；模型几何改变，或旧校准文件没有几何指纹时，原位姿仍可恢复，但需要重新人工确认。非有限位姿、无效关节和循环关系会在修改场景前拒绝。

调试调整只影响展示配置。包围盒重叠或网格相交结果不能直接证明穿模、公差合理或装配可制造。装配配置见 `state/`。

## 工作区结构

| 目录 / 文件 | 用途 |
| --- | --- |
| `src/` | Rust 源码与 WGSL 着色器 |
| `config/` | 首次启动配置、展示规则和打印参考配置 |
| `vendor/gridfinity-rebuilt/` | 保留许可证的第三方 SCAD 生成源码 |
| `tools/` | 生成器安装脚本；本地安装的 OpenSCAD 不纳入 Git |
| `state/` | 用户设置、装配配置和生成缓存，不纳入 Git |
| `output/` | 本地导出、截图与验证报告，不纳入 Git |
| `target/` | Cargo 构建产物，不纳入 Git |
| `Cargo.lock` | 锁定依赖版本 |

原模型库应放在工作区之外；请勿将原始模型包或含原模型的导出工程随软件发布。
