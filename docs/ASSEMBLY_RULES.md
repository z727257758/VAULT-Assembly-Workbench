# 装配与运动规则

装配策略统一由 [`constraints::AssemblyRules`](../src/constraints/rules.rs) 的一个 `impl` 管理。新增规则和运动入口从这里接入；界面不再自行决定运动范围或锁扣联动。原有 `basic_relations`、`sustainer::set_lid_angle`、`explosion::reset` 等入口保留为转发，供现有代码和回归使用。

## 职责与入口

| 入口 | 管理内容 |
| --- | --- |
| `initialize` | 根据源清单生成初始姿态、配色与示意拆解，再按模块族建立精确定位关系。未支持的抽屉保留示意几何并记录原因。 |
| `family` / `AssemblyKind` | 界面、保存格式与几何处理共用一个类型；旧 `sustainer::is_scene` 仅转发该判断，外部配件不会另行改变分类。 |
| `assemble_drawer` | 模块支承抽屉滑动关节。前面板和内轨固定在抽屉上，中间轨由抽屉行程驱动，侧面止挡和底部卡闩固定在模块上。 |
| `layout` | 统一堆叠和外部配件检查。添加、改规格、移动、保存、载入和后台组合加载复用此入口。 |
| `installation_height` / `pull_limit` | 安装面名义高度只定义一次；拉杆行程直接读取布局计算的支承链顶高。 |
| `preview_lid_angle` | 支承上层的翻盖箱在组合中闭盖，保留方案内原有开盖偏好。运行时显式开盖同样检查支承关系。 |
| `shared_shell` | 共用外壳固定各层的侧面止挡。每个子抽屉使用自己的滑动轴、闭合基准和两段导轨行程。 |
| `set_joint_value` | 统一运动入口；根据零件 `PartId` 修改滑动或铰链参数，箱盖自动采用锁扣联动。 |
| `set_slider` | 修改指定抽屉在父件局部坐标系中的滑动距离，并核对该关节实际保存的行程上下限。 |
| `mechanism` / `plan_motion` | 定位具体成员／子抽屉的关节，核对有效行程、锁扣完整性与支承状态，并生成分段运动轨迹。 |
| `plan_latch` | 在抽屉或箱盖闭合时，单独驱动选中对象的锁件。 |
| `apply_motion_sample` | 每帧重新核对约束后求解关节与后代姿态，不重读 STL、不重新生成网格、不改变爆炸位移。 |
| `set_lid_angle_for` | 只修改指定箱盖及其所属成员的内外锁扣；其他成员保持装配姿态。 |
| `set_lid_angle` / `lid_angle` | 单箱盖便捷入口。多个箱盖时不能隐式选择第一个，修改须给出具体 `PartId`。 |
| `reset_explosion` | 按每个成员自身的类型重新计算展示拆解，再按层与列分开成员；失败整体回滚。 |
| `space_combination` | 仅为已有爆炸展示增加成员间留白，不改变装配位置及关节。 |

`constraints.rs` 继续负责有向约束图和求解；每个子件只有一个父件，根件保持固定，按拓扑顺序传播变换。`module_assembly`、`front_panel`、`runners`、`geared_rails`、`baseplate`、`sustainer` 等保留各源件的平面、孔轴和安装基准算法。`scene.rs` 创建中性实例并管理共用外壳和组合元数据，不再保存另一套初始朝向、装配位置或爆炸规则。`catalog.rs` 管理源路径匹配，`collision.rs` 管理后台三角面交叉诊断。源文件解析和装配定位仍在后台完成。

`stacking::Layout` 提供列边界 `column_starts` 和名义顶高 `nominal_tops`。界面的左右插入直接使用这些边界，拉杆直接使用这些顶高，不再各自重算列宽或复制层高表。它们是规则计算的派生缓存，不写入项目文件。

## 开盖状态的唯一提交路径

项目内的 `Preset::sustainer_angle` 是开盖偏好的保存来源；`App` 编辑缓存和 `Scene` 关节是派生状态。普通开盖控件与关系面板均通过 `app::motion` 的统一提交函数更新。关系面板先在候选场景求解，成功后才将实际角度写回所属成员，并同步当前成员的编辑缓存，随后提交候选场景。失败不修改配置或实时场景。

重新生成预览、切换成员和保存项目都继续读取该偏好。接受关系面板的开盖修改后，会用新偏好替换旧的待处理预览请求，避免新角度被旧缓存或后台旧请求覆盖。动画目标在开始播放时提交一次，逐帧姿态是该目标的派生状态。其他成员的偏好不变；作为支承的箱盖仍由统一规则保持闭合，不删除其保存的开盖偏好。

抽屉在各自 `Preset::drawer_extension` 保存 0–1 的目标抽拉比例，旧方案缺省为 0。重建时先以闭合关节计算安装面和尺寸，再按每个子抽屉的有效行程恢复目标比例，改深度时不会沿用不适合新规格的毫米数。共用外壳的各子抽屉分别保存，不能用外壳整体作为多个滑动关节的隐式目标。

## 装配规则

| 对象 | 规则 | 依据与边界 |
| --- | --- | --- |
| 堆叠 | 同宽同深；L ↔ S＋S，XL ↔ S＋M；抽屉与翻盖箱可混用。要求完整覆盖、支承等高，拒绝悬空、重叠、自由偏移和自由间距。 | 总说明书第 8 页给出兼容关系；具体安装面由源网格估算。 |
| 抽屉 | Runner Slide 安装在抽屉侧槽，Runner Guide 套住内轨，在模块槽中滑动。Runner Stopper 固定在模块侧孔，伸入中间轨的长槽。 | 抽屉安装说明步骤 6、9–11 给出安装关系。两段可用行程按对应深度的源件几何估算。 |
| 共用外壳 | 子抽屉高度总和等于外壳层高，最多四个，禁止递归嵌套；各子抽屉保持独立标识、内部配置和标牌。 | 容量由 `constraints::tower` 校验；槽距为当前模型定位估算。 |
| 翻盖箱 | 箱体为根；前面板及锁座固定到箱体，顶盖和上铰链绕后部轴线运动；下铰链和轴杆留在箱体。 | 翻盖箱安装说明步骤 5–10，源件孔轴与安装面用于定位。 |
| 外部配件 | 底座只能位于地面成员；独立顶盖和拉杆不能占用被上层支承对象占用的顶部；拉杆伸出量受支承链高度与插入余量限制。 | 继续由 `constraints::exterior` 执行，统一纳入 `layout`。详细边界见 [组合规则](COMBINATION_RULES.md)。 |

## 运动规则

机械运动与爆炸展示分别管理：

- **滑动**：`Joint::Slider` 的轴在父件局部坐标系中。旋转模块后，抽屉仍沿模块自身的抽拉方向运动，面板、底板、盒子及其他后代一起跟随。越界或非有限输入直接拒绝，不静默截断。
- **二段导轨**使用一个抽屉总行程。预览中先让内轨相对中间轨滑动，接近挡肩后，由内轨带动中间轨继续伸出，直至长槽接近壳体止挡。推回时沿原轨迹返回。每段预留 0.2 mm 展示间隙。多组导轨共用同一抽屉时，总行程取各组允许值中的最小值。手册给出装配顺序，实际伸出先后和打印件可用行程仍待实物核对。
- **抽屉旋钮**转到手册步骤 7 的水平位置时解锁。装有齿条时，上下齿条同步向相反方向各收回约 13.3 mm。预览转角取 60°，按源网格每 18° 对应 4 mm 的齿距换算。S3、M3、L3 的抽样检查发现，继续转到 65° 时凸轮与壳体出现表面交叉。已保留齿轮过渡肩及面板孔缘的局部网格接触诊断，实物行程待核对。完全解锁后才拉出抽屉，推到底后再反转上锁。隐藏钥匙的锁芯、活动头和端盖沿同一轴转动。
- **开盖**：`Joint::Hinge` 保存父件局部轴和支点。支承上层的箱盖必须保持闭合。开启轨迹先释放内外锁扣，再抬盖；关闭轨迹先完全落盖，再扣锁。外扣转角扣除内扣已转动的部分，避免重复计算相对转动。缺少内扣／外扣、锁扣不同步或未释放就抬盖时拒绝运动。轨迹使用关节变换，不模拟弹性、解锁动力学，也未验证实物连续行程。
- **多成员隔离**：通过源路径、实例号和展示实体号组成的 `PartId` 定位。成员与共用外壳子抽屉各自有实例命名空间。同名 STL 不表示同一运动目标；多个箱盖时必须显式选择实例。
- **失败回滚**：在候选场景中修改关节、求解位置并刷新派生展示位移，全部成功后才提交。后续爆炸布局失败也不会留下已经移动的半完成场景。
- **爆炸展示**：`Pose::travel` / `travel_frame` 仅描述拆解展示偏移，继承父装配的拆解量，再叠加各自提取方向。组合重排使用运行时保存的层／列元数据，逐成员派发抽屉或翻盖箱算法；重复重排不会累计偏移。跨成员关节尚无拆解分组规则时明确拒绝重排。
- **闭合尺寸**：开盖和抽拉不改写保存的闭合外形读数；展示间距不进入打印摆盘和源 STL。

## 动画操作

在抽屉浮动编辑面板点击“解锁／上锁”可单独转动旋钮。在翻盖箱面板点击“松扣／扣合”可单独操作正面搭扣。两种操作都保持抽屉或箱盖闭合。点击“拉出／推回”或“开盖／合盖”会自动串联锁件动作。中途反向从当前姿态开始。共壳抽屉可独立操作。

动画运行时只更新 `Joint` 参数与求解后的姿态，保留网格资源。完成后才刷新爆炸展示布局；进入爆炸、分层、打印板或尺寸视图会暂停播放。手动修改同一运动关节会取消它原有的播放，并同步新的目标姿态。改结构或重建模型会清除播放过程，用已经保存的目标状态重建。播放时间和暂停阶段属于临时状态，不写入项目文件。相机按路径包围范围取景，避免后续的闭合姿态对焦覆盖它；包围范围不作为碰撞或安全间隙判据。

## 集中参数与证据等级

以下参数集中在 `AssemblyRules`；它们不是手册公布的制造公差或经过实物验证的机械极限。

| 参数 | 当前值 | 用途 |
| --- | --- | --- |
| `LID_ANGLE` | 0–110° | 程序的开盖展示范围；界面、方案校验和关节默认范围共用。 |
| `LOCK_ANGLE` | −180–180° | 锁扣铰链允许的展示参数范围。 |
| `DRAWER_SLOT_PITCH` | 48 mm | 共用外壳内的源槽距估算。 |
| `DRAWER_FIRST_HEIGHT` / `SUSTAINER_FIRST_LID_RISE` | 47 / 14 mm | 名义安装面高度：抽屉为 47＋(F−1)×48；1F 翻盖箱再加 14。保留原有 47／61／95／191 mm 预检值。 |
| `PULL_LOCK_RESERVE` / `PULL_EXTENSION` | 38 mm / 0–800 mm | 拉杆锁座余量与允许的配置范围；复用支承链顶高计算行程。 |
| `MIN_PULL_ROD_LENGTH` | 61 mm | 采购拉杆示意的最小长度，区别于安装面高度计算。 |
| `DRAWER_REAR_RETENTION` | 20 mm | 缺少成套导轨行程数据时，用抽屉深度减去此余量估算预览上限。 |
| `DRAWER_FLOOR_GAP` / `DRAWER_REAR_GAP` | 2 / 0.7 mm | 当前抽屉源网格的底部和后部定位余量。 |
| `FACE_GAP` | 0.2 mm | 前面板／弹簧面的初始贴合余量。 |
| `LID_SPEED` / `DRAWER_SPEED` / `LATCH_SECONDS` | 120°/s / 220 mm/s / 0.25 s | 播放时间基准；只是动画速度，不是实物性能参数。 |
| 锁扣闭合／释放展示角 | `config/sustainer-locks.toml` | 由统一实现读取，按 1F、高箱体和 XL4 源件选择。 |

安装手册没有给出可直接采用的完整抽拉上限和箱盖极限角，因此保留这些参数的展示／估算属性。包围盒只用于显示留白；包围盒重叠不是已证实的穿透，未检出三角面交叉也不是 CAD 装配或制造验证。

## 本轮手册核对

只读查看用户模型库中的 `01_Instructions Manual.pdf` 第 8 页、`02_Drawer Assembly.pdf` 第 6–8 页，以及 `03_Sustainers Assembly.pdf` 第 3–6 页。核对了堆叠组合、前面板与滑轨安装、先推入后装止挡、底部卡闩、上下铰链与穿杆及前锁面板安装顺序。没有将图片中的示意角度当作尺寸标注。

原始 PDF 和 STL 留在外部模型库；本地核对图片位于 `output/assembly-rules/`。新加的成员布局元数据只存在于运行时 `Scene`，旧方案的字段和校准文件格式保持兼容。

## 验证

```powershell
cargo fmt --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings

# VAULT_MODEL_ROOT 指向已有的只读模型库
cargo test --locked library_mixed_members_use_independent_lids_locks_sliders_and_repeatable_extraction -- --ignored --nocapture
cargo run --release --locked -- --smoke-test --smoke-combination
cargo run --release --locked -- --smoke-test --smoke-motion
```

纯规则回归检查旋转父件后的局部轴、成员隔离、运动与爆炸偏移分离、非法输入及后续失败的整体回滚、重复爆炸重排、外部配件下的类型一致性、共享高度下的行程和空列旁的插入。开盖保存回归检查独立成员和 TOML 往返；原生组合回归通过同一关系面板提交函数改角度，重建预览后再次检查配置、编辑缓存和关节值一致。外部库回归同时装入抽屉和两个翻盖箱，检查显式箱盖选择、仅所属成员锁扣联动、其他成员姿态不变以及重新计算展示的稳定性。

原生 `--smoke-motion` 使用三个 S3 模块，包含作为支承的翻盖箱、共用外壳双抽屉和顶部翻盖箱。测试会检查旋钮与端盖同转、两根齿条反向移动、箱盖闭合时单独松扣，以及整套机构的开合和复位。它也覆盖中途反向、共壳抽屉隔离、支承约束、闭合尺寸和项目重载。截图与结果保存在 `output/motion-ui/`。
