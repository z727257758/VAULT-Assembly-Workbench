# Sustainer 箱子装配实施前分析

当前状态（2026-11-01）：已从源网格提取孔轴、接触面和连接槽，替换首版示意摆放。已知源件偏差、未解决的表面相交和验证边界见文末“几何定位与配合核对”；下文实施前分析及首版状态作为历史依据保留。

分析对象：用户本地 `261021_VAULT_USSA_S` 模型包。模型库只读；原说明书和 STL 不复制到仓库。

## 已核对的装配关系

`03_Sustainers Assembly.pdf` 共 7 页、12 步：

| 步骤 | 装配关系 |
| --- | --- |
| 1–2 | 小销连接 Lock Holder 与 Lock Inner Part；大销连接 Inner 与 Outer，注意 UP 朝向。 |
| 3–4 | 锁组件固定在前面板上，使用 M4 × 14 mm。 |
| 5–6 | 上铰链固定到顶盖（M4 × 14 mm），下铰链固定到箱体（M4 × 10 mm）。 |
| 7–8 | 顶盖与箱体通过铰链配合，并插入两根轴杆。 |
| 9–10 | 前面板固定到箱体（M4 × 20 mm），再插入标签。 |
| 11–12 | 移除手工支撑，再安装所选隔板。 |

箱子不使用抽屉的 Box、Runner Guide、Runner Slide、Geared Rails、Key、Springs 或 Latch。应使用独立的 BOM 和约束图：箱体为根，前锁面板固定到箱体，锁组件从属于面板；顶盖绕后部铰链轴开合，上铰链跟随顶盖，下铰链和轴杆从属于箱体。

总说明书第 17 页标注每套 M4 × 14 mm 16 个、M4 × 10 mm 8 个、M4 × 20 mm 7 个。该图使用 L 型示例；不能据此断言所有 S/M/XL 规格都有相同的螺钉数量。五金没有对应 STL，不应伪装成已建模零件。

## 文件覆盖与匹配

箱子目录包含 **225 个 STL**：

- S/M/L：3–7 格深度，1F/2F/4F；XL：3–7 格深度，仅 1F，共 50 个尺寸组合。
- S/M 每种尺寸只有一种 Module；L/XL 提供 Flat、Dividers、Sealed 三种 Module。S/M 不应虚构三个箱体变体。
- 深度 3–5 顶盖为整体件；6–7 同时有 Whole、Part 1、Part 2 和 Connector。整盖与分体盖是互斥方案，不能同时加入打印清单。
- `Roof` 与 `Roofs` 目录混用；M Module 的扩展名前有空格；存在 `M4f`、`L4F'`、`XL3  Roof`、`XL6  Roof Whole` 等实际命名。需要在 catalog.rs 中规范化匹配，并保留实际源路径。
- 家族目录和 Universal/Facades 中存在同规格面板候选。九组 S/M/L 候选的 STL 字节与三角面数均不同，不能认定是相同网格的副本；需要比较安装孔和锁槽，再确定使用哪个版本。两组不能自动同时装上。
- `Label for Sustainers.stl` 与抽屉 `Label.stl` 不同，现有抽屉文字加工逻辑不能直接用于箱子标签。
- 箱子底板位于 Universal/Baseplates，隔板位于 Universal/Dividers；现有抽屉内部编辑器的网格、槽位和放置高度不能直接沿用。

## STL 几何核对

完整尺寸和三角面清单保存在本地 `output/sustainer-analysis/stl-inventory-fast.json`。尺寸假定 STL 单位为 mm。

| 示例 | 原始 STL 轴向包围盒（X × Y × Z）mm | 含义 |
| --- | --- | --- |
| S3 1F Module | 164.806 × 50.800 × 146.100 | 原始 Y 为层高方向，不能按 STL 的 Z 直接当高度。 |
| S1F 面板 | 164.802 × 46.000 × 10.000 | 正面板独立于箱体。 |
| S3 Roof | 130.431 × 122.301 × 156.097 | 在 XY 平面斜放，轴向宽度不代表真实盖宽。 |
| S Hinge Top | 14.000 × 57.000 × 62.800 | 一份 STL 中检测到一个连通实体。 |
| M Hinge Top | 14.000 × 57.000 × 98.800 | 一份 STL 中检测到一个连通实体。 |

S3 Roof 的主平面法线约为 `(0.679, -0.734, 0)`；沿其垂直方向测得约 164.8 mm 宽，而不是包围盒的 130.4 mm。不能套用现有 scene.rs 中固定的 `-45°` 顶盖示意旋转，其他尺寸也需要单独检查主平面。

按 0.0001 mm 顶点焊接进行连通分析：

| 源文件 | 每份 STL 的连通实体数 |
| --- | --- |
| S-M 1F Hinge / S-M 2-4F Hinge | 2 |
| L-XL 1F Hinge / L 2-4F Hinge | 2 |
| S Hinge Top / M Hinge Top | 1 |
| L-XL Hinge Top | 2 |
| S-M Rods / L-XL Rods | 2 |
| 1 SET OF PINS FOR 1 LOCK | 4 |

连通实体数量不等于最终物理零件数量：原 STL 可能带手工支撑，需要结合图示区分。特别是 S/M 上铰链，不能因 L 示例图有两个铰链就把源文件打印份数直接设为 2。展示拆分只改变显示实例，打印清单仍以源文件份数计数。

## 实施边界与顺序

1. catalog.rs 增加独立箱子选型和 BOM：实际路径解析、同规格面板单选、整盖/分盖互斥、按规格选铰链和锁外件。本次已检查全部 50 个尺寸组合，箱体、家族面板和顶盖均有实际文件，矩阵见本地 `output/sustainer-analysis/size-matrix.json`。
2. display.rs 增加经过实体数核对的只读拆分规则。手工支撑只在确认识别规则后从显示网格移除，保留源 STL 和导出打印几何。
3. scene.rs 创建箱子实例；单独的箱子装配模块从几何平面建立箱体、盖和面板基准。constraints.rs 增加绕锚点的铰链关节，固定其他组件；禁止复用抽屉滑动关节。
4. app.rs 开放箱子方案、箱体类型和整盖/分盖选择、开盖预览（可先使用 0–110° 作为展示范围，这不是已验证的机械行程）；方案和校准坐标使用独立键保存，避免覆盖同尺寸抽屉配置。
5. 先校准 S3/1F 与 L3/1F 的上下铰链、轴杆、锁和标签，再覆盖 M、2F/4F、XL 与分体盖。未核对的变换必须保持“估计 / 未校准”。
6. 复用选中、隔离、颜色、透明和爆炸预览，保持 STL 解析在后台。箱子内部布局、标签文字及分体连接件在专用配合确认后接入，不能以抽屉规则自动猜测。
7. 修改代码后运行 cargo fmt、cargo test、cargo clippy，并用原生 --smoke-test 检查闭盖、开盖、爆炸和回归抽屉场景。网格表面相交诊断只能作为辅助，不能宣称完成 CAD 或制造验证。

## 当前证据不足的项目

## 几何定位与配合核对（2026-11-01）

定位使用两个截面匹配安装孔中心，以实际圆柱弧拟合轴线，并按有向平面定位实际承压面。数值计算使用双精度；初始包围盒只帮助选择特征，最终安装位置依据孔阵列和局部平面。自动结果均保持 `calibrated=false`，不替代用户的人工确认。软件孔轴检查阈值为 0.2 mm、共轴检查为 0.02 mm、主要接触面为 0.03 mm；这些是检查阈值，不能当作制造公差。

| 对象 | 定位与关系修正 |
| --- | --- |
| 前面板 | 对齐箱体前安装孔，背面与箱体正面安装面贴合。 |
| 下铰链 | 按四孔及真实背安装面固定到箱体，轴位于箱体后侧；修正原先翻转方向。S3/1F 的铰链轴约为世界 Y=25.398、Z=−80.648 mm。 |
| 上铰链及顶盖 | 上铰链的安装板位于销轴上方；raw |X|=7 mm 的外缘承压面贴合顶盖内面，|X|=4.95 mm 的凹面避让盖上的凸台。顶盖整体平移到上下轴线重合。L/XL 上下铰链轴向位置相错约 45.5 mm，不应放在相同 X。 |
| 轴杆 | 使用真实轴心，保留源件的左右头部方向，圆头按孔圆柱段位置定位；杆与孔的拟合径向差约 0.20 mm，头部实际接触及打印支撑仍待复核。 |
| 前锁 | 支座 UP 方向为 raw −X；法兰位于前面板内侧，以朝外安装面贴合内壁（原版装配说明第 2 页步骤 3–4）。内扣 raw +X 的端部双耳连接支座，raw −X 的中间连续轴套连接外扣。开盖预览先松扣。 |
| 销钉 | 源件为自由弯曲弹性销钉；装配预览对截面居中并限制名义直径 5.5 mm，形成伸直展示近似。源 STL、单件预览和打印导出保留原始自由形态；未进行受力或弹性变形验证。 |
| 标签 | 1F 按匹配槽底轮廓和接触面定位。2F/4F 使用较长的 D 形侧入槽，将标签置于矩形槽底区域；横向止挡、滑入间隙未确认。 |

源件及装配展示仍存在以下待核对项：

- **M 全部 21 组**：箱体横向安装孔距约 22.75 mm、下铰链为 23 mm，居中后每孔约偏 0.125 mm；相邻上下铰链端面轴向间隙约 −0.125 mm。端面测量提示不能直接等同于实体穿透证明。

原始 STL 始终只读。卡扣采用下面说明的局部表面核对；箱体及顶盖仍保留部分打印支撑，其他相交未全部排除，不能把局部检查通过当作完整 CAD 或制造验证。0–110° 仍仅是展示范围。

`--calibrate-sustainers` 在启动图形界面前完成离线解析，覆盖 126 组箱体/顶盖组合，将坐标和关系保存到 `state/assembly-sustainer-*.toml`，核对报告写到 `output/sustainer-calibration/report.md` 和 `report.json`。已人工确认的定义不会被覆盖，其候选数据写入 output。普通预览仍在后台提取几何，不在 UI 线程读取 STL。旧版未确认的示意坐标会迁移到新定位；已人工确认的坐标予以保留。

验证包括全规格真实网格、已知孔距/端面差异的回归，代表规格的开盖及内外锁件父子联动、保存恢复、旧示意数据迁移，分盖槽轮廓，以及原生闭盖、开盖、爆炸、密封箱和分盖截图。详细测试日志及表面相交记录位于本地 `output/sustainer-calibration/`。

### 卡扣穿模修正

此前只对齐销轴、随后又强制弯钩圆角中心与顶盖圆角中心重合，均未约束完整轮廓，不能作为无穿模证据。本次从实际相交对复核了以下定位问题：

- 支座四孔对称，倒装仍可对孔。源刻字 UP 箭头沿 raw −X，原来装反；刻字平面证据见本地 `output/sustainer-calibration/holder-up-levels.png`。
- 内扣 raw X≈+7.5 mm、R≈2.85 mm 的孔只在两端耳片存在，应该与支座中间轴套配合；raw X≈−7.5 mm、R≈2.95 mm 的孔贯穿中间连续轴套，应该与外扣双耳配合。两者配反会使连续轴套互相嵌套，尽管轴线检查仍通过。
- 原先把支座背面贴在面板外侧的解释有误。原版说明书第 2 页显示四孔底板在箱内侧。当前使用面板内侧 Z=−5 mm 与支座朝外面（旋转后 Z=−4.45 mm）定位；相较旧版，S3/1F 支座向内移动约 15 mm。
- 上铰链原先翻面，错误使用另一侧的 X=0 平面，使顶盖偏低约 7 mm；已按实际承压边缘和凹面方向修正，保持上下销轴共线。

移除不合适的圆角同心闭锁条件，按完整硬件/扣位截面选择有局部间隙的展示姿态。参数独立保存在 `config/sustainer-locks.toml`，分 1F、2–4F 及 XL4 较高顶盖特例。它们不是经实物确认的闭锁止挡。源销钉的自由弯曲形态在刚性显示中会与孔壁相交，因此仅在装配展示中使用伸直近似，打印导出仍由 export.rs 直接读取源 STL。

中间角度检查发现，箱盖抬到 1° 就会碰到仍闭合的卡扣。预览先分别转动内扣和外扣两个关节至松开姿态，再改变盖角；外扣角度扣除父级内扣的转动，避免继续用整套刚体旋转将外扣摆回面板内。闭盖恢复展示锁定姿态。没有验证连续松扣运动路径或机械行程。旧版未人工确认的顶盖、上铰链和卡扣坐标及关系一并迁移；人工确认文件予以保留。

局部表面检查涵盖支座、内外扣及装配销钉与其他组件，使用 0.05 mm 阈值的三角面穿越诊断；检测要求两个三角面各自跨越对方平面，且有限交线有超过阈值的重叠；使用双精度避免把槽边与法兰边界相邻误报为穿越。单侧贴面接触、共面接触和完全包容不等同于该诊断能证明的穿透。补充了法兰贴面接触与真正双向穿越的区分测试、轴套分布和 UP 方向回归、旧状态迁移，以及代表规格 0°、1°、5°、15°、30°、45°、75°、110° 的相交与联动检查。

全规格卡扣诊断写入 `output/sustainer-calibration/report.json` 的 `latch_surface_crossings`；多角度记录见 `surface-report.json`。原生预览见 `output/native-sustainer-closed.png` 和 `output/native-sustainer-open.png`。这些结果说明展示姿态的局部诊断结果，不替代实体尺寸、受力、弹性装配或制造验证。

### 内壁安装面修复的验证边界

闭锁展示角度在修正安装面后重新核对，内扣 −8°、外扣 9.5°（XL4 外扣 10.5°）；松扣时分别为 −90° 和 0°。这些角度仅用于装配展示，不是机械止挡或连续运动验证。

部分 1F 源件的支座背面 UP 凸字顶部与顶盖内沿仍有局部相交提示，S3/1F 的相关高度范围约 0.1 mm。保留凸字和原始顶盖，不移动已对齐的安装面来掩盖此提示。0.05 mm 诊断完整记录所有相交；只有闭盖时落在已测量凸字范围内、并且同一对在 0.2 mm 诊断中不再检出的结果，才标为 holder_marking_review。该标记表示待复核，不表示无干涉。其他卡扣相交仍使离线核对失败；界面为 1F 配置保留文字提示。

回归增加了底板螺孔承压区必须位于面板内侧、顶盖前沿不得落入面板、上铰链安装板朝向、有限三角形交线边界误报，以及新版坐标迁移与人工确认保护。全规格仍覆盖 126 组；代表规格继续核对 8 个盖角。原 STL、打印导出方向与网格不改变。

本次修复验证：cargo fmt、cargo test --locked（132 通过，1 项既有手动测试忽略）、cargo clippy --locked --all-targets -- -D warnings 通过。带真实模型库的 5 项 Sustainer 回归通过，包含 126 组内侧安装面和顶盖前沿检查、7 组代表规格的 8 个盖角、迁移和人工校准保护。离线核对更新 126 份未确认定义，未归类卡扣相交为 0 组；53 组 1F 配置保留 UP 凸字局部相交提示。最终 release 原生 --smoke-test --smoke-sustainer 通过，已检查闭盖、开盖、爆炸、密封箱及分体盖画面。
