# 组合装配规则

依据用户外部模型库中的原版《01_Instructions Manual》第 6、8 页，以及《05_Mounting Instructions》第 12 页。源 PDF / STL 只读，不随仓库分发。

## 规格兼容

- 第 8 页：同宽同深可上下堆叠，盒子（Sustainer）与抽屉可混合。
- L 可对应两个 S；XL 可对应 S＋M；两边都必须完整覆盖、深度一致。
- 支承模块的顶面须等高。不能仅凭 1F / 2F 名称假设所有类型等高；Sustainer 1F 的闭合顶盖高度与抽屉 1F 不同。
- 用户通过对象的左侧、右侧、上方及地面指定位置，自动对齐；禁止悬空、空间重叠、自由偏移及统一间隙。旧方案的放置索引保留在内部，不作为用户操作概念。
- 每次添加、尺寸修改、移动 / 交换和删除都先检查候选组合，失败不应用。保存、载入和后台场景加载复用检查。

## 两个页面

整体页直接在三维预览中选择对象，通过模型旁的方向按钮选尺寸、确认添加或成组添加。预览工具条负责修改尺寸、移动和删除；移动时点目标对象再选择方向，支持 Esc 取消和撤销。单件页只读规格，保留内部布局、标签、配色和结构选项。尺寸变更默认保留内部配置；不兼容时拒绝，可明确勾选重置内部配置，标签和配色保留。返回整体页保持选中成员和原视角。

成对成员可以同时移到地面后独立修改，或同时删除；若这对成员仍支承上层则拒绝移除。操作保留成员内部配置。

## 尺寸显示

后台在闭合状态下逐顶点计算每个成员的世界坐标外形范围，并组合得到整体尺寸；旋转模型不使用旋转前包围盒的角点估算尺寸。显示宽 × 深 × 高（含外伸件），源单位按 mm。三维标注使用缓存结果，相机旋转和开盖不改变读数。尺寸显示不等于实物测量，也不表示接口已经验证。

## 安装面估算的边界

在后台从箱体水平大平面提取外底面、上安装面；盒子取闭合顶盖的外面，按背面与规格宽度对齐。选取宽度来自源模块族的名义接口宽度（S 164.8、M 254.0、L 329.6、XL 418.8 mm）；不采用标签 / 卡扣 / 开盖状态的包围盒作为堆叠高度。

UI 的等高预检使用源网格测得的安装面间距：抽屉 1F / 2F / 4F 为约 47 / 95 / 191 mm，盒子约 61 / 95 / 191 mm。后台重新测量实际源件，检查支承面高度（容差 0.25 mm）。这些是估算的面到面定位基准，不是手册公布的机械配合尺寸，也不证明连接器已经正确啮合。组合始终保持未验证标记。

连接锁扣仍由各成员装配规则配置。作为支承的盒子在整体预览中闭合顶盖，单件保存的开盖角度不变。

部分 XL 分体抽屉原有装配尚未提供可信的箱体朝向，本实现拒绝将它们标成已按安装面定位；XL 盒子支持规则组合。大 STL 流式读取并分块上传显卡（单件 800 万 / 场景 1600 万三角形上限），不再使用 250 MB 截止值。源文件损坏或超过几何预算时显示具体错误，不跳过必需零件拼成残缺模型。

## 验证

纯规则测试覆盖同规格混合类型、L / XL 成组支承、不同深度、不完整支承、悬空、同层重叠及支承高度不齐。设定 VAULT_MODEL_ROOT 后的 library_seating_datums_and_orientation 测试只读检查 S / M / L / XL、深度 3 / 7、可用高度及两种类型，结果写入 output/combination-rules/seating-datums.txt，明确列出源文件错误和未支持的安装面。

原生 --smoke-test --smoke-combination 覆盖整体 / 单件切换、标签同步、整体页尺寸修改、不兼容修改和移动拒绝、确认添加及删除，并输出截图。几何检查与烟测不等于实物或 CAD 验证。

新增整体装配回归测试位于 `src/app/combination/regression.rs`，覆盖 560 种同规格堆叠、240 种 L / XL 双向配对及 20 种深度不匹配情况，并检查三层支承、64 成员边界、删除支承、重复移动选择、配对左右顺序、反复拆装后的邻居位置、独立配置保存和取消加载。`scene.rs` 另检查满容量成员标识隔离，以及空缺 / 非有限位移输入的错误返回。

三项外部模型库回归默认忽略，可单独执行（PowerShell；变量指向原有只读模型库）：

```powershell
$env:VAULT_MODEL_ROOT = '模型库绝对路径'
cargo test app::combination::regression::library_ -- --ignored --test-threads=1
```

实测覆盖六组混合类型、不同规格及双向配对，检查源安装面、内部约束图和闭合尺寸；开盖测试检查支承盒闭盖、上层盒保留开盖角度且保存配置与尺寸不变。大 XL 抽屉测试要求成功读取大文件后明确返回尚未支持的朝向校准错误，不把它计作装配成功。矩阵结果写入 `output/combination-regression/library-matrix.txt`；测试不向模型库写入任何文件。


## 整体外部配件

在整体预览选中成员，点击“安装配件…”（侧栏也有“安装 / 修改配件…”），按底部、背部、顶部配置。选择把手或挂板会补选连接板，顶部提手补选 Grid 顶盖；确认后再应用，取消保留原配置。“清除全部配件”也需确认应用。单件页仍只负责内部配置和原有机构。

已接入整体底座、双轮＋脚撑、1F / 2F 背部连接板、固定把手、拉杆及锁座、IKEA / USSA 挂板接口、Grid / Table / Bowl / Under Table Mount 顶盖、顶部提手和壁挂组件。底座随宽深选择整体源件（深度 6 / 7 使用 Whole）；不缩放原始 STL。固定把手 / 挂板与拉杆锁座分别配置到不同成员，避免重复占用背板安装区域。拉杆锁座替代所选成员的普通连接板，不在同一位置叠放两块。伸出量按支承链塔高限制，保留锁座内的插入余量；改动下方模块高度时重新检查。

底座只能装在地面成员，独立顶盖和拉杆要求顶部没有支承对象，盒子不加装抽屉独立顶盖。移动、改尺寸、保存、载入、复制和导出保留并复查配件配置。源文件缺失或不唯一时拒绝应用，不生成残缺配件组。底座抬高整个支承链；双支承高度不一致会拒绝预览。独立堆叠组按含配件的闭合外形自动排开；同一支承组内保留接口位置并做保守的侧向配件空间检查，包围范围重叠不等于已证明网格穿透。

配件保存于每个组合成员的 exterior 字段，旧方案缺省为空。打印导出包含配件源件，并另写 hardware.txt；M16 拉杆是已知直径的采购件示意，未列入打印源件。轴承、紧固件等采购件仅列在清单中。显示尺寸包括实际预览的几何，不能作为未建模五金、墙面和桌板的完整安装空间。

源底座 / 顶盖通过大平面法向恢复打印前的装配朝向，再核对名义宽度；按源平面估算接触位置。轮轴孔在源底座坐标中距底面 20 mm、距后端 30 mm；拉杆锁座和提手的源孔位分别参与定位。所有配件关系仍标为估算，不能视为孔位、紧固连接和承载能力已验证。配件变换仅用于预览，不改写源 STL。

文档边界：
- 改装说明推荐底座上方、顶盖下方用 2F，界面作为建议显示。
- 35 mm 拉杆锁紧螺栓在改装说明与总手册中存在 M4 / M6 标注冲突，采购清单保留待核对说明。
- 4F 背板跨层安装、分体底座、重载顶盖及无源模型的四脚轮尚未接入；不能用相似零件替代并声称正确装配。
- 依据外部只读文档 04_Modifications 第 2–15 / 17 页、01_Instructions Manual 第 3 / 10 / 19 页、05_Mounting Instructions。模型库和原文档不复制入仓库。

验证命令：
- cargo test：配件依赖、位置限制、非法配置、旧方案缺省、往返保存、移动保留与缺失 / 歧义文件检查。
- 设置 VAULT_MODEL_ROOT 后，cargo test library_exterior_ -- --ignored --test-threads=1：100 组底座 / 顶盖源规格朝向，五组装配、四种宽度的拉杆、独立组留空以及真实导出清单。
- vault-native.exe --smoke-test --smoke-exterior：原生配件截图、约束图稳定性与未验证标记检查；结果保存在 output/assembly-accessories-review/。
